# Инструкции проекта

Проект предназначен для англоязычных учебных материалов по механике: лабораторных работ, презентаций, тестов и списков задач.

## Работа с материалами

- Для нового материала или существенной переработки используй skill `physics-material-workflow`.
- Для набора, сборки и исправления LaTeX используй skill `physics-latex-authoring`.
- Для схем и рисунков TikZ используй skill `physics-tikz-figures`.
- Исходные файлы преподавателя в `source/` считаются неизменяемыми. Производные материалы создавай рядом, но не перезаписывай оригиналы.
- Весь текст, видимый в итоговых PDF, включая заголовки, задания, решения, подписи, легенды и TikZ-метки, пиши только на английском. Входные материалы и рабочая документация могут быть на другом языке.
- Каждый материал веди по `PLAN.md` и `WORKLOG.md`. Не переходи через контрольную точку без явного подтверждения пользователя. Подтверждение заноси в журнал.
- Лабораторные работы оформляй как Beamer-презентации 16:9 через `physicslabslides.cls`, а не как A4-документы.
- Если в материале есть задачи или вопросы с ответами, поддерживай обе версии: `main.tex` без решений и `solution.tex` с решениями. Общий текст держи в `content.tex`.
- Не выдумывай экспериментальные данные, условия, формулы или ответы. Неясности выноси в план как вопросы.

## Сборка

- Используй цели `make`, которые запускают закреплённый Docker-образ. Не полагайся на локальную установку TeX.
- Генерируемые файлы должны находиться только в `output/`.
- Перед передачей результата выполни `make lint` и собери изменённые точки входа.
- После успешной сборки визуально проверь PDF: переполнения, обрезку, читаемость с проектора, нумерацию, единицы измерения, английские подписи и отсутствие кириллицы. Для лабораторных и презентаций отдельно проверь формат 16:9.
